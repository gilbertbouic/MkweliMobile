## 🚀 HOW TO BUILD

### Prerequisites
```
✅ Node.js >= 20
✅ npm installed
✅ Android SDK (for APK)
✅ Or Xcode (for iOS)
```

### Build Steps
```bash
# 1. Install dependencies
npm install

# 2. Run tests (verify everything works)
npm test

# 3. Check coverage
npm test -- --coverage

# 4. Build APK
./build-apk.sh

# 5. Install on device
adb install android/app/build/outputs/apk/*/app-*.apk
```
